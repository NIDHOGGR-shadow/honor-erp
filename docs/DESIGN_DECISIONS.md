# Inventory-first decisions

Honor is an inventory product for company teams. Every initial screen should support the path catalogue → receive → store/transfer → issue/sell → count/reconcile → replenish.

The company administrator controls people, permissions and locations. The platform operator maintains the service; unrestricted support impersonation is not a default feature.

CRM and sales are supporting modules. A standalone CRM pipeline and general ERP expansion wait until the inventory workflows are correct and validated by a company.

The existing Store visual language is retained. The first pass changes hierarchy, spacing, navigation and access presentation rather than introducing a new visual identity. Detailed responsive visual verification is pending, as recorded in DELIVERY_STATUS.md.
